## Before any of these can be published

1. The client confirms it holds a media release for **every** identifiable person
   in the frame.
2. Where any subject is a minor, the release is signed by a parent or guardian.
3. The frame is checked for visible team logos, uniforms, or venue marks that
   would imply a school, club, or partner affiliation that has not been confirmed.
4. Only then is the frame added to `coachPhotos` in `lib/content/media.ts` with a
   public export under `public/media/coach/`.

Alternative if releases cannot be obtained: publish with the other identifiable
people obscured, or keep the frame out of the public site entirely.
